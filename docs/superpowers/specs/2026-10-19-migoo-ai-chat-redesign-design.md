# Migoo-Style AI Chat UI Redesign for Kiko AI

**Date:** 2026-10-19  
**Status:** Approved  
**Target:** `lib/mobile/screens/support/kiko_ai_chat_screen.dart` & `lib/web/widgets/kiko/web_kiko_chatbot_widget.dart`

---

## 1. Overview & Objective
Redesign AgriDirect's existing AI assistant (Kiko) to adopt the clean, modern e-commerce conversational UI inspired by TikTok Shop's "Migoo" AI assistant. The goal is to provide a visually striking, welcoming, and user-friendly chat experience featuring a glowing iridescent hero mascot, tailored suggestion pills, quick category shortcuts, and a streamlined capsule input bar.

---

## 2. Visual & Structural Specifications

### 2.1 Minimalist Header / Top Bar
- **Back / Profile Action**: Clean profile outline icon (`Icons.person_outline_rounded`) or back navigation chevron depending on modal/embedded context.
- **Center Title**:
  - Title: **Kiko** (Bold, `GoogleFonts.poppins`, 17px, `#111827`).
  - Subtitle: **Generated by AI** (`GoogleFonts.inter`, 11px, `#9CA3AF`).
- **Right Action**: Chat transcript / history icon (`Icons.description_outlined` or `Icons.receipt_long_outlined`), providing quick options to reset chat or view previous topics.
- **Background**: Solid white (`#FFFFFF`), elevation `0`, borderless separator.

### 2.2 Hero Mascot & Greeting Card (Welcome State)
- **Iridescent Halo / Mascot Bubble**:
  - Multi-color sweep gradient border ring with vibrant hues: Magenta (`#E11D48`), Purple (`#8B5CF6`), Sky Blue (`#0284C7`), Amber (`#F59E0B`).
  - Inner white circular pad housing the Kiko Carabao mascot (`assets/images/kiko_happy.png`) with crisp scaling and smooth rendering.
- **Welcome Bubble**:
  - Container background: Soft neutral gray (`#F3F4F6`), border radius `18px`.
  - Greeting Copy:
    > *"Hi, I'm Kiko, your AgriDirect AI assistant. Tell me what you need, and I'll find reliable options, compare what matters, and help you choose what fits you best."*
  - Typography: `GoogleFonts.inter`, font size `14px`, weight `w400`, color `#1F2937`, line height `1.45`.

### 2.3 Curated Suggestion Chips (Prompt Tags)
- **Layout**: Staggered wrap / vertical flow of pill-shaped prompt chips directly under the welcome card.
- **Styling**:
  - Background: Pure White (`#FFFFFF`).
  - Border: Subtle gray border (`1px`, `#E5E7EB`).
  - Border Radius: `14px`.
  - Padding: `8px` vertical, `14px` horizontal.
  - Typography: `GoogleFonts.inter`, font size `13px`, font weight `w500`, color `#1F2937`.
- **Role-Adaptive Content**:
  - **Consumer (Shopper) Mode**:
    1. *"Find best deals"*
    2. *"Fresh harvest nearby"*
    3. *"Trending organic produce"*
    4. *"Sun protection & farmer tools"*
    5. *"How to store leafy greens"*
  - **Farmer Mode**:
    1. *"Live weather & irrigation advice"*
    2. *"Pricing guide for upcoming harvest"*
    3. *"Pest and crop disease diagnosis"*
    4. *"How pre-orders & harvest milestones work"*

### 2.4 Quick Category Shortcut Bar
- **Position**: Pinned directly above the bottom input bar.
- **Components**: Horizontally scrollable row of compact capsule buttons with icons:
  - `[🛍️ Shopping]` — filters prompts to marketplace & buying
  - `[🎟️ Voucher]` — displays discount vouchers & promo prompts
  - `[📥 Inbox]` — prompts order status & message inquiries
  - `[📦 Pre-Orders]` (or `[🌤️ Weather]` in Farmer mode)
- **Styling**: White background (`#FFFFFF`), rounded borders (`16px`), border `#E5E7EB`, padding `6px 12px`.

### 2.5 Bottom Capsule Input Bar
- **Container**: Floating capsule container (`borderRadius: 28px`), background `#F3F4F6`.
- **Leading Attachment Button (`+`)**:
  - Plus icon (`Icons.add_rounded`, size `22px`, color `#1F2937`).
  - Tapping opens image selector (Camera for live crop diagnosis / Gallery for photos).
- **Text Field**:
  - Hint text: *"Anything on your mind?"* (`GoogleFonts.inter`, font size `14px`, `#9CA3AF`).
  - Multi-line support up to 3 lines with clean auto-scroll.
- **Trailing Action**:
  - Microphone icon (`Icons.mic_none_rounded`, size `22px`, `#1F2937`) when text is empty.
  - Active Send button (`Icons.arrow_upward_rounded` or `Icons.send_rounded`) with an emerald green circular badge when text is present.

---

## 3. Conversational Behavior & Message Thread
- **Welcome View to Message Thread Transition**:
  - The hero mascot and suggestions remain cleanly at the top of the chat history or scroll smoothly as conversational bubbles enter the feed.
- **Message Bubbles**:
  - **User**: Deep emerald gradient (`#059669` to `#047857`), white typography, rounded corners with user-side tail.
  - **AI Assistant**: Soft white/gray card (`#FFFFFF`), subtle border `#E2E8F0`, rich markdown rendering (headers, bold, lists), and interactive follow-up chips.
- **Live Integration**:
  - Preserves multi-turn conversation context with Gemini AI (`AiService`).
  - Preserves live weather integration (`WeatherService`).
  - Preserves crop disease diagnosis with photo uploads.
  - Desktop web responsiveness: Constrained to center column (max width 680px) on wide displays.

---

## 4. Verification & Testing Criteria
1. UI fidelity matches reference screenshot (Migoo aesthetic with Kiko Carabao).
2. Tapping any suggestion chip sends the prompt and receives a formatted response from the AI.
3. Tapping category shortcuts filters or triggers appropriate prompts.
4. Camera/Image upload (`+` button) continues to work smoothly for photo attachments.
5. Voice/Mic button renders and text input toggles seamlessly to send button when typing.
6. Responsive on mobile devices and centered cleanly on desktop web.
